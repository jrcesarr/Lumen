# 0001. Back em Python com FastAPI

**Contexto.** O case sugere Node, mas a diretoria de Computacao da ITA Jr ja entrega em Python (SmartFit) e a Lumen tera recursos de IA.

**Decisao.** FastAPI + SQLAlchemy async + Alembic.

**Consequencias.** Reaproveitamos padroes e pessoas que ja conhecem a stack. Ecossistema de IA e dados mais maduro. Front segue em TypeScript, entao o time ainda precisa dominar as duas linguagens.
